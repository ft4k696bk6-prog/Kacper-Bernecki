# Codex Prompt

You are working on `Kacper-Bernecki`, an interactive 3D MacBook portfolio website.

## Current Scope

Build and refine a polished portfolio experience:

- React + Vite + TypeScript.
- Three.js landing scene with a right-profile MacBook on a luxury minimalist table.
- Smooth GSAP camera orbit around the table, MacBook opening animation, and final transition into the laptop screen.
- Interactive desktop with app icons, dock actions, panels, external links, terminal commands, contact shortcuts, booking, and games.
- Games: Snake, Pong, Breakout, plus an external Berni Rush shortcut.
- Functional icons for GitHub, LinkedIn, static portfolio, email, phone, and Cal.com booking.
- Responsive desktop and mobile layout with touch-friendly controls.

## Constraints

- Do not copy an existing portfolio 1:1.
- Keep the implementation original and professional.
- Keep visible controls functional, not decorative.
- Avoid copyrighted game assets.
- Validate the Three.js scene visually on desktop and mobile before shipping.
